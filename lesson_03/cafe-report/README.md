# Cafe Report

Программа читает заказы кофейни из файла `data/orders.csv` и печатает отчёт:
количество заказов, выручку, средний чек и суммы по официантам.

Внешних библиотек нет, нужен только Python 3.10 или новее.

## Запуск

Команды выполняются из корня проекта — из папки, в которой лежит код программы.

```
python -m venv .venv
python -m app.main
python -m unittest discover -s tests -v
```

На Windows вместо `python` может потребоваться `py`, а окружение активируется
командой `.\.venv\Scripts\Activate.ps1`.

## Дерево проекта

```
cafe-report/
  app/            код программы
    services/     расчёты по заказам и сборка отчёта
    utils/        деньги и строки, без правил этой кофейни
  data/           файл заказов, не код
  docs/           описание того, как устроены суммы и имена
  tests/          проверки расчётов и отчёта
```

Файл лежит там, где лежит его ответственность: `orders.py` читает заказы, `report.py` собирает строки отчёта, `money.py` переводит копейки в рубли, `text.py` выравнивает имена.
