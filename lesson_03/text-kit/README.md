Text Kit печатает короткий разбор строк, чисел, контактов и дат: заголовок, среднее, телефон и число дней между двумя датами.

Функции разделены по теме, а не по порядку в старом файле. Строки и даты пригодятся в любом проекте, поэтому они лежат в `app/utils/`. Среднее, медиана и проверка почты, телефона и пароля — правила этого набора, они лежат в `app/services/`.

## Дерево

```
text-kit/
  app/main.py                  только запуск и примеры данных
  app/utils/text.py            пробелы, обрезка, инициалы, адрес страницы
  app/utils/dates.py           разбор даты, выходной, число дней
  app/services/statistics.py   среднее, медиана, разброс, подсчёт значений
  app/services/validation.py   почта, телефон и замечания к паролю
  tests/                       девятнадцать проверок
```

`is_email` пользуется `clean_spaces` из модуля строк. Остальные модули друг друга не импортируют, а `main` не импортирует никто.

## Запуск

Команды из папки `text-kit`:

```
py -m app.main
py -m unittest discover -s tests -v
```
